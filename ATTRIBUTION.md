# Attribution and provenance

OpenAI Codex assisted with the project concept, application code, scheduling engine, styling, tests, debugging, demo material and documentation. No AI API, remote model or paid service is used when the application runs.

The app, icon and synthetic example tasks were created for this project beginning October 28, 2026. Verification and usability repairs continued on November 6. The screenshots are unedited captures of the actual application using synthetic data. Typography uses installed system fonts; no stock images, remote fonts or image-generation assets are included.

Node.js runs the optional localhost server and test runner. happy-dom 21.0.4, licensed under MIT, provides the development test DOM and is not loaded by the application. The package-lock.json pins its dependency graph. Installing development dependencies retains their respective license files. Native browser APIs provide the interface, localStorage, downloads and dialogs.

The runtime app has no npm dependencies. It performs no analytics, remote API calls or telemetry. All initial tasks and benchmark workloads are synthetic and contain no real student's coursework.

The planning score expresses priorities and a fixed energy preference. It does not predict grades, wellbeing or productivity. The synthetic benchmark compares the implemented search with its included greedy baseline; it does not demonstrate student outcomes.

The implementation applies general scheduling techniques: chronological dynamic programming, bounded beam search, prerequisite masks and a greedy baseline. It is not copied from an external scheduling library.
